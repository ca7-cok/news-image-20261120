One image summing up the world's news of **Friday 20 November 2026**: Russia pounds Kyiv in an overnight missile and drone barrage after Putin vowed revenge for the Crimea Bridge strikes, the EU and UK strike new post-Brexit deals in Brussels, GTA 6 smashes records with $2.36 billion in first-day sales, the COP31 draft drops any call to phase out fossil fuels, and Estonia seals its border with Russia.

`render.py` draws the 1024×1024 infographic with Pillow (run locally to produce `entry.png`); `main.py` is the entry point the grader runs — standard library only, it copies `entry.png` to `/output/entry.png`, byte-identical on every run.

## Run it

```sh
python3 render.py
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
